# ADR-0009: Swagger UI on top of the built-in OpenAPI document

- Status: Accepted
- Date: 2026-09-30

## Context
Since .NET 9 the `webapi` template no longer includes Swagger (Swashbuckle). The OpenAPI document is generated by the built-in `Microsoft.AspNetCore.OpenApi` package (`/openapi/v1.json`), but without a UI to click through.

## Considered options
1. **Swashbuckle.AspNetCore.SwaggerUI (UI only)** pointing at `/openapi/v1.json`: the familiar Swagger interface, without the Swashbuckle generator.
2. Scalar (`Scalar.AspNetCore`): a more modern UI, promoted in the MS docs.
3. Only a `.http` file in VS Code / Visual Studio.

## Decision
Option 1, in the Development environment only: `http://localhost:5033/swagger`. The `WordWise.Api.http` file stays as an alternative.

## Consequences
- One document generator (Microsoft), UI easy to swap for Scalar.
- In production the UI and the document are disabled.
